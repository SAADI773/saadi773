# Featured Projects

## EDUBot — University Admission RAG

An AI-powered university information and admission assistant designed to provide contextual answers from university documents.

**Built With:**
`LangChain` `Groq` `ChromaDB` `Python` `Next.js` `Sentence Transformers`

### Key Work

* Retrieval-Augmented Generation architecture
* Document processing and chunking
* Vector database integration
* Semantic search
* Embedding-based retrieval
* AI-powered question answering
* University-focused knowledge base

---

## Finzo — Developer-First Payment Gateway

A payment infrastructure concept designed around the needs of **freelancers, software houses, developers, and e-commerce businesses**.

The vision is to build a developer-friendly payment platform capable of supporting digital payments, API-based integrations, cross-border transactions, and local PKR settlements.

**Status:** Product Development / Design Phase

---

## GitDev — GitHub Repository Evaluator

A developer-focused platform designed to evaluate GitHub repositories and help assess project quality, structure, and development practices.

The project focuses on making repository evaluation more practical for students, developers, mentors, and technical teams.

---

## MyUOG / UOGBox

A university-focused digital resource platform designed to organize academic material by:

**Block → Department → Semester → Course → Resources**

The goal is to make university academic resources easier to access and manage through a structured digital experience.
